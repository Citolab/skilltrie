# Reports

## Overview

A Report represents an issue with an Item, flagged by a User. Reports are created whenever a question is considered incorrect, incomplete or contains problems that prevent it from being answered properly.

Reports allow the classification of different types of errors that users encounter, making it easier to review and fix problematic items. **Reports are created manually by users** who notice discrepancies, meaning the content of a report is subjective and may contain human errors.

## Report Structure

Each report is represented by the `Report` interface. A report stores essential information linking a detected issue to the specific item it refers to.

```ts
export interface Report {
    id: number;
    itemId: number;
    itemError: ItemError;
}
```

### Field Description

| Field       | Type        | Description                                                                                                                    |
| ----------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `id`        | `number`    | Unique identifier of the report. Each report created in the system receives its own ID.                                        |
| `itemId`    | `number`    | The identifier of the item (question) the report refers to. This creates the link between the report and the problematic item. |
| `itemError` | `ItemError` | The type of error that was reported. This value classifies the issue according to the predefined error types.                  |

## Error types

The system classifies issues using the `ItemError` type:

```ts
export type ItemError =
    | "QTextEmpty"
    | "QTextIncorrect"
    | "ATextEmpty"
    | "ATextIncorrect"
    | "AnswersWrong"
    | "GraphicsUnavailable"
    | "GraphicsFaulty"
    | "GraphicsUnrelated"
    | "OtherError";
```

### Error Type Description

| Error                 | Meaning                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------ |
| `QTextEmpty`          | The question text is missing or completely empty.                                          |
| `QTextIncorrect`      | The question contains incorrect, misleading, or invalid information.                       |
| `ATextEmpty`          | The answer text is missing or not provided.                                                |
| `ATextIncorrect`      | The answer is incorrect, incomplete, or does not match the question.                       |
| `AnswersWrong`        | The available answer options are incorrect, inconsistent, or do not correspond to reality. |
| `GraphicsUnavailable` | A referenced graphic is missing or cannot be loaded.                                       |
| `GraphicsFaulty`      | The graphic exists but is corrupted, wrong, or technically unusable.                       |
| `GraphicsUnrelated`   | The graphic does not relate to the question or provides irrelevant information.            |
| `OtherError`          | Any issue that does not fit the predefined categories.                                     |

## Report Creation

Report are created through the **Report Form** component, which is integrated into the [QTI Player](../frontend/QTI-player.md). When users encounter an issue while interacting with an item, they can click the Report button displayed. This action opens the report form, allowing users to select one or more error types and send the report to the backend.

The backend receives a `ReportPayload`, which contains all necessary information to create a report, except the `id`, which is generated by the database:

```ts
export type ReportPayload = Omit<Report, "id">;
```
