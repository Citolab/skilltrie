From an item picker [(see item pickers documentation)](ItemPickers.md), we want to select a fixed amount of items. Normally you do that with `resultList.Take(n)`. However sometimes there are less than n items and we want another item picker to fill in the gap. That is what the `ItemPickerChain` class is for. You can add item pickers to the chain and then call `PickNItems(ICollection<Item> availableItems, int itemAmount)` which will return `itemAmount` items if there are enough items in the entire chain. If not an exception is thrown.
