# Cosmetic

## Overview
A `Cosmetic` represents a visual customisation that a `User` can own or purchase.
Cosmetics define avatar customisation such as clothing, hairstyles and accessories.
Each cosmetic specifies its price, the currency required to purchase it, and Rive animation data used by the rendering system. 
Cosmetics are stored in a .riv file, where the artboard, state machine, and input values determine the visual behaviour.


```csharp
public class Cosmetic
{
    public int Id { get; init; }
    public string Name { get; init; } = null!;
    public int Price { get; set; }
    public Currency Currency { get; init; } = null!;
    public int CurrencyId { get; init; } = 1; 
    public ClothingType ClothingType { get; init; }
    public string RiveFile { get; init; } = null!;
    public string RiveArtboard { get; init; } = null!;
    public string RiveStateMachine { get; init; } = null!;
    public string RiveInput { get; init; } = null!;
    public int RiveInputValue { get; init; }
    public bool DefaultOwned { get; init; }
    public string IconFile { get; init; } = null!;
}
```

### Field description

| Property           | Type           | Description                                                                         |
| ------------------ | -------------- | ----------------------------------------------------------------------------------- |
| `Id`               | `int`          | Primary key, generated by the database.                                             |
| `Name`             | `string`       | Display name of the cosmetic.                                                       |
| `Price`            | `int`          | Price of the cosmetic.                                                              |
| `Currency`         | `Currency`     | Navigation property linking the cosmetic to the currency used for purchase.         |
| `CurrencyId`       | `int`          | Identifier of the currency required to buy this cosmetic.                           |
| `ClothingType`     | `ClothingType` | Category of cosmetic.                                                               |
| `RiveFile`         | `string`       | Path to the `.riv` animation file used by the frontend renderer.                    |
| `RiveArtboard`     | `string`       | The artboard name inside the `.riv` file that this cosmetic is associated with.     |
| `RiveStateMachine` | `string`       | The state machine controlling the cosmetic animation behaviour in the `.riv` asset. |
| `RiveInput`        | `string`       | The input used by the state machine to trigger cosmetic animations.                 |
| `RiveInputValue`   | `int`          | The value used to activate or configure the cosmetic state in the Rive animation.   |
| `DefaultOwned`     | `bool`         | Whether new users receive this cosmetic automatically upon account creation.        |
| `IconFile`         | `string`       | Path to the icon displayed on the frontend for selection or purchase.               |



## Data Transfer Objects (DTO's)

### CosmeticDto
`CosmeticDto` is a data transfer object used to communicate cosmetic data between the frontend and backend.
It excludes the `DefaultOwned` property, as ownership assignment occurs during user creation and is therefore handled exclusively on the backend.

```csharp
public class CosmeticDto
{
    public int Id { get; init; }
    public string Name { get; init; } = null!;
    public int Price { get; set; }
    public int CurrencyId { get; init; } = 1;
    public string ClothingType { get; init; } = null!;
    public string RiveFile { get; init; } = null!;
    public string RiveArtboard { get; init; } = null!;
    public string RiveStateMachine { get; init; } = null!;
    public string RiveInput { get; init; } = null!;
    public int RiveInputValue { get; init; }
    public string IconFile { get; init; } = null!;
}
```
