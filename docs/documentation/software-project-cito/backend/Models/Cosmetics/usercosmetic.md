# UserCosmetic

## Overview
A `UserCosmetic` tracks the ownership and equipped state of a cosmetic purchased or assigned to a User. 
Each record links a user to a cosmetic and indicates whether the cosmetic is currently active on the user's avatar. 
New `UserCosmetic` entries are created when a user acquires a cosmetic or when default cosmetics are assigned during account creation.

```csharp
public class UserCosmetic
{
    public int Id { get; init; }
    public int UserId { get; init; }
    public User User { get; init; } = null!;
    public int CosmeticId { get; init; }
    public Cosmetic Cosmetic { get; init; } = null!;
    public bool Equipped { get; set; }
}
```

### Field description

| Property     | Type       | Description                                                                |
| ------------ | ---------- | -------------------------------------------------------------------------- |
| `Id`         | `int`      | Primary key, generated by the database.                                    |
| `UserId`     | `int`      | Identifier of the user that owns the cosmetic.                             |
| `User`       | `User`     | Navigation property linking the record to the user.                        |
| `CosmeticId` | `int`      | Identifier of the cosmetic this record tracks.                             |
| `Cosmetic`   | `Cosmetic` | Navigation property linking the record to the corresponding cosmetic.      |
| `Equipped`   | `bool`     | Indicates whether the cosmetic is currently equipped on the user's avatar. |



## Data Transfer Objects (DTO's)

### UserCosmeticDto
`UserCosmeticDto` is used to communicate the ownership and equipped state of a cosmetic on the frontend. 
It provides only the identifiers and equipped flag, without including navigation properties.

```csharp
public class UserCosmeticDto
{
    public int UserId { get; init; }
    public int CosmeticId { get; init; }
    public bool Equipped { get; set; }
}
```
