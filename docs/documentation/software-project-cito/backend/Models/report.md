# Report

## Overview

A Report represents feedback submitted by a user indicating that a specific Item contains incorrect, incomplete, or otherwise problematic content. While the frontend handles the creation and submission of reports, the backend is responsible for storing, managing, and providing access to them.

Reports are persisted in the database and linked to the items they refer to. This enables administrators or automated processes to inspect and resolve reported issues.

```csharp
public class Report
{
    public int Id { get; init; }
    public int ItemId { get; init; }
    public Item Item { get; init; } = null!;
    public ItemError ItemError { get; init; }
    public DateTime CreatedAt { get; init; } = DateTime.UtcNow;
}
```

### Field description

| Property    | Type        | Description                                                                         |
| ----------- | ----------- | ----------------------------------------------------------------------------------- |
| `Id`        | `int`       | Primary key, generated by the database.                                             |
| `ItemId`    | `int`       | Foreign key referencing the reported item.                                          |
| `Item`      | `Item`      | Navigation property enabling access to the associated item when retrieving reports. |
| `ItemError` | `ItemError` | Enum describing the type of issue reported.                                         |
| `CreatedAt` | `DateTime`  | Timestamp noting when the report was created. Defaults to `UtcNow`.                 |
