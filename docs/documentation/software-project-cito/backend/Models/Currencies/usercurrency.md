# UserCurrency

## Overview
A `UserCurrency` represents the balance a `User` holds of a specific `Currency`. Each entry links a user to a currency and tracks the user's current amount. 
New `UserCurrency` records are created automatically when a user is initialised, with the starting balance determined by the associated `Currency`’s default value.

```csharp
public class UserCurrency
{
    public int Id { get; init; }
    public int UserId { get; set; }
    public User User { get; set; } = null!;
    public int CurrencyId { get; set; }
    public Currency Currency { get; set; } = null!;
    public int Amount { get; set; }
}

```

### Field description

| Property     | Type       | Description                                                                                           |
| ------------ | ---------- | ----------------------------------------------------------------------------------------------------- |
| `Id`         | `int`      | Primary key, generated by the database.                                                               |
| `UserId`     | `int`      | Identifier of the user that owns the currency.                                                        |
| `User`       | `User`     | Navigation property linking the record to the user.                                                   |
| `CurrencyId` | `int`      | Identifier of the currency this record tracks.                                                        |
| `Currency`   | `Currency` | Navigation property linking the record to the corresponding currency.                                 |
| `Amount`     | `int`      | The user's current balance of this currency. Initialised using the currency's `StartingAmount` value. |


## Data Transfer Objects (DTO's)

### UserCurrencyDto
`UserCurrencyDto` is used to communicate a user's balance between the frontend and backend. 
It omits the navigation properties that the `UserCurrency` object contains.

```csharp
public class UserCurrencyDto
{
    public int UserId { get; init; }
    public int CurrencyId { get; init; }
    public int Amount { get; set; }
}
```

### UserCurrencyUpdateDto
`UserCurrencyUpdateDto` is used when a request is made on the frontend to modify a user's balance.
Besides the navigation properties, it also omits the `UserID`, because the current user is inferred from the authenticated session.

```csharp
public class UserCurrencyUpdateDto
{
    public int CurrencyId { get; init; }
    public int Amount { get; set; }
}
```
