# Currency

## Overview
A `Currency` represents a type of in-system unit that users can own, spend, or acquire. Each currency defines its display name, icon reference used by the frontend, and a default starting balance. The starting amount is assigned automatically when a new `User` is created, enabling systems to construct user balances without manual initialization.

```csharp
public class Currency
{
    public int Id { get; init; }
    public string Name { get; init; } = null!;
    public string Sprite { get; init; } = null!;
    public int StartingAmount { get; init; } = 0; 
}

```

### Field description

| Property         | Type     | Description                                                                               |
| ---------------- | -------- | ----------------------------------------------------------------------------------------- |
| `Id`             | `int`    | Primary key, generated by the database.                                                   |
| `Name`           | `string` | Display name of the currency.                                                             |
| `Sprite`         | `string` | Path to the icon of the currency used by the frontend.                                    |
| `StartingAmount` | `int`    | Balance assigned to a new user when the currency is initialised for them. Default to `0`. |


## Data Transfer Objects (DTO's)

### CurrencyDto
`CurrencyDto` is a data transfer object for currency communication between the frontend and backend. 
It omits the `StartingAmount` property, as this value is only required during user initialisation, a process handled exclusively on the backend.

```csharp
public class CurrencyDto
{
    public int Id { get; init; }
    public string Name { get; init; } = null!;
    public string Sprite { get; init; } = null!;
}
```
